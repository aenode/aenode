## @aenode/plugin

Nx plugin that provides a set of project generators.

## Install

```sh
  bun add -D @aenode/plugin
```

## Examples

Generate a new library project

```sh
bunx nx g @aenode/plugin:library <library-directory>
```

Generate a library configuration for the existing project

```sh
bunx nx g @aenode/plugin:project-config <project-name>
```
